# Thunder Fighter 雷霆战机

基于 Qt 5.9.9 与 C++ 开发的纵版弹幕射击游戏。

## 快速开始

### 下载即玩

从 Releases 的v4.0版本下载 `ThunderZone.zip` ，解压缩后双击 `FirstThunderFighter.exe` 即可运行。

**系统要求**：Windows 7 及以上，64 位操作系统。

### 从源码编译

**环境要求**：
- Visual Studio 2022
- Qt 5.9.9（msvc2017_64）
- Qt VS Tools 插件

**编译步骤**：
1. 使用 Git 克隆仓库
2. 在 VS 中打开 `FirstThunderFighter.sln`
3. 选择 **Release x64** 配置
4. 生成解决方案（`Ctrl+Shift+B`）

## 操作说明

| 按键 | 功能 |
|---|---|
| 方向键 / W A S D | 移动战机 |
| 1 | 炸弹清屏（清除全屏敌弹，冷却 3 秒） |
| 2 | 能量护盾（3 秒无敌，免疫伤害） |
| 3 | 火力增强（伤害提升至 2 倍，持续 7 秒） |
| Esc | 暂停 / 继续 |

## 计分规则

| 事件 | 分数 |
|---|---|
| 击毁普通敌人 | +150 |
| 击毁精英敌人 | +300 |
| 击毁 Boss | +5000 |
| 被击中 | -500/次（最多计 10 次） |
| 收集道具 | +200/个（最多计 20 个） |

## 游戏内容

### 敌人
- **普通敌人**：基础敌兵，缓慢随机漂移
- **精英敌人**：更强的火力与耐久度
- **Boss**：三个阶段，每个阶段拥有不同的弹幕模式

### Boss 太空原种 弹幕系统

**第一阶段**：
扇形扩散压制、直线压制+追踪弹、圆环弹幕、海胆阵列+角度扫射、尾弹扫射、弹幕牢笼等

**第二阶段**：
扇形扩散压制、直线压制+追踪弹、海胆阵列+扫射、跟踪弹簇射等

**第三阶段**：
十字形弹幕、追踪弹雨、旋转四向扇弹、粉尘弹幕、海胆阵列+S 形扫射、网状弹幕等

## 项目结构

```
FirstThunderFighter/
├── main.cpp                 # 程序入口
├── GameWidget.h/.cpp        # 主游戏窗口（菜单、战斗、渲染）
├── GameTypes.h              # 通用数据结构（子弹、敌人、粒子等）
├── Boss.h/.cpp              # Boss AI 与弹幕系统
├── Player.h/.cpp            # 玩家飞机与技能
├── EnemyUnit.h/.cpp         # 普通/精英敌人
├── Background.h/.cpp        # 滚动背景
├── BgmManager.h/.cpp        # 音乐管理
├── res/                     # 资源文件（图片、音效、BGM）
└── FirstThunderFighter.*    # VS 项目文件
```

## 技术特性

- 固定数组子弹管理（无动态分配，性能稳定）
- 预渲染 QPixmap 弹幕缓存（海胆弹、V 形弹、侧向弹、直线弹）
- 三阶段 Boss AI 状态机
- 多种弹幕模式（扇形、追踪、阵列、旋涡、牢笼、网状交织等）
- 三级火力系统与技能系统
- DMA 映射背景音乐
